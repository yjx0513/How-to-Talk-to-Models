  🎯 微调（Fine-tuning）在哪里体现？

  微调体现在三个层面：

  1. LoRA 参数微调 (src/models/t5_lora.py:54-66)

  if use_lora:
      peft_cfg = LoraConfig(
          r=8, lora_alpha=16, lora_dropout=0.05,
          target_modules=["q", "k", "v", "o"],  # 只微调注意力层的投影矩阵
      )
      model = get_peft_model(model, peft_cfg)
      model.print_trainable_parameters()  # 显示只有<1%参数可训练
  - 冻结原T5模型，只训练LoRA注入的低秩矩阵
  - 可训练参数通常只有原模型的 0.1%~1%

  2. 训练流程 (src/train.py:121)

  trainer.fit(lit, datamodule=dm)  # PyTorch Lightning训练循环

  3. 训练配置 (configs/e2e.yaml:23-36)

  train:
    lr: 2.0e-4          # 学习率
    epochs: 5           # 训练轮数
    train_batch_size: 2
    grad_accum: 16      # 梯度累积=32有效batch

  4. 优化器 (src/models/t5_lora.py:115-128)

  def configure_optimizers():
      # 区分weight decay和no decay参数
      opt = torch.optim.AdamW(params, lr=self.lr)
      return opt

  ▎ 你在做参数高效微调（PEFT）：冻结T5-base的220M参数，只训练LoRA加的少量适配器参数（~1M），让模型学会"结构化数据→文本"
